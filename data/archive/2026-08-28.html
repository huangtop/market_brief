本日重點財經事項

  1. NVIDIA 財報與供應承諾倍增（★★★★★）。

    要點：NVIDIA 報告第二季業績強勁、當季營收報導為 962 億美元（市場公開數字），並對下一季給出約 1080 億美元的營收展望；公司在財報與電話會中披露，對供應鏈的「未來元件/產能承諾」從上季約 1190 億美元跳升至 2790 億美元，管理層並表示記憶體（HBM / AI server memory）為目前主要瓶頸，預期短中期仍將是限制因子。一次資訊的直接一階 read‑through：NVIDIA 的大幅採購承諾與記憶體瓶頸宣告，會直接推升 HBM/高階 DRAM 與相關封測/先進封裝的訂單與 ASP 預期，並提高對電力、機櫃冷卻與高功率電源模組（PSU / HVDC / 800V）短中期需求。來源：NVIDIA 財報公告 來源：The Motley Fool

  2. AWS 與 NVIDIA 擴大合作、宣布額外部署 200 萬顆 NVIDIA GPU（★★★★☆）。

    要點：AWS 與 NVIDIA 共同發布計畫，將在 2027–2028 年間於 AWS 全球基礎設施中再部署約 2,000,000 顆 NVIDIA GPU（包含 Blackwell 系列與 Rubin 系列等），同時深化在 CPU、網路、AI 工廠與機器人領域整合。對六條主線的一階影響：大量新增 GPU 部署會直接拉動 XPU（GPU）出貨與 memory（HBM/DDR5/AI server memory）需求，並增加 data‑center 層級的電力（PSU、HVDC、機櫃供電設計）與光連接需求（高帶寬互連與光收發器）。來源：AWS / Amazon 聲明 來源：Nasdaq / GlobeNewswire

  3. 產業直接風險與價格傳導（★★★★☆）。

    要點：NVIDIA 明確將記憶體視為成長限制，此一公開立場已立即改變市場對 HBM/高階 DRAM 供需節奏的判斷。短期內，記憶體供應緊張會推升記憶體廠商議價能力與 ASP；同時，伺服器廠與電源/散熱供應鏈面臨更明顯的交付時程與資本支出要求（例如為新增 GPU 機櫃升級到更高電壓/更大功率的 PSU 或 HVDC 配套）。此為一階推論，不作二階個股受惠預測。來源：Reuters / Investing 來源：Seoul Daily
