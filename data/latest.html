昨夜科技資金輪動\

\

\CPO & Optical｜高速光通訊出現跨公司同步重挫，從前期領漲族群轉為主要賣壓來源。\ 10月12日Ciena（CIEN）下跌約10%、Lumentum（LITE）下跌約9.8%、Coherent（COHR）下跌約7.9%，三家公司跌幅均顯著超過費城半導體指數的2.67%。這次異動發生在OCP全球峰會開幕當天，市場對高速光互連技術的長期需求仍有期待，但前期股價漲幅已充分反映相當高的成長預期。 \

\

主要壓力來自兩個方向：一是OCP既定展示未帶來足以再次提高營收預期的意外催化劑；二是Broadcom執行長陳福陽提出AI擴張可能受到資本限制，使市場重新評估大型雲端業者的遠期設備採購。光通訊的產業成長方向仍由800G、1.6T及更高密度光互連推動，但股票定價開始更重視交付時程、產能擴張效率與實際現金流。 \MarketWatch\ \

\

\Memory / XPU｜記憶體與AI運算晶片同步走弱，市場提高對資本支出回報的要求。\ Micron下跌約3.9%，AMD下跌約2.3%，NVIDIA下跌約1.3%。Micron受到中國長鑫存儲新型DRAM架構進展的市場討論影響；AMD與NVIDIA則在OCP發布新一代AI系統技術之際，仍面臨半導體族群整體賣壓。 \

\

這次輪動最值得注意的是，市場開始區分「技術路線持續升級」與「投資回報何時實現」。AMD的新型代理式AI機架、NVIDIA的Vera Rubin開放式設計，以及高速網路規格升級，都增加了AI基礎設施的技術選擇；資金則更關注大型客戶的正式部署規模、設備交付與營收成長速度。 \Investor's Business Daily\ \

  1. \★★★★★ ASIC / AI Infrastructure｜Broadcom執行長指出資本將成為AI成長主要限制，產業競爭焦點由晶片供給延伸至客戶融資能力\ \

    Broadcom執行長陳福陽10月12日在新加坡公開活動表示，AI產業正逐步克服晶圓與記憶體供應限制，未來持續擴張的主要挑戰將是資本取得。這項判斷將AI基礎設施研究焦點從半導體製造能力，進一步推向大型運算園區的融資與資本回報。 \Reuters｜10月12日\ \

    \

    AI運算系統的成本已經超越單顆GPU或ASIC，涵蓋HBM、先進封裝、高速網路、液冷、供電與資料中心建設。即使晶片供應能力持續增加，客戶仍需要充足資本完成設備採購及園區部署。大型雲端業者的資本支出、AI服務收入與自由現金流，因此會更直接地影響上游半導體供應商的中期成長。 \

    \

    對ASIC供應鏈而言，值得關注的是客製化晶片專案從設計導入、晶圓投片、封裝到正式交付的資金安排。客戶預付款、長期採購承諾與實際設備部署，將影響Broadcom、Marvell及先進封裝供應商的收入能見度。 \

    \

    \下一個觀察重點：\ Broadcom與Marvell後續AI半導體營收指引、大型雲端客戶2027年資本支出、AI服務變現速度，以及新資料中心專案的融資條件。 \

  2. \★★★★★ XPU｜AMD推出Helion代理式AI機架，CPU與GPU混合架構成為新一代AI系統設計方向\ \

    AMD於10月12日正式發表Helion代理式AI機架，採用開放式硬體與軟體設計，提供純CPU及整合EPYC CPU、Instinct GPU的不同系統配置，並加入模型請求路由功能，協助客戶依工作負載選擇運算資源。 \AMD官方新聞稿\ \

    \

    代理式AI系統需要執行模型推論、工具調用、資料處理、任務排程及多階段工作流程。這些工作負載對CPU核心密度、記憶體容量、網路延遲與GPU加速的需求各不相同。Helion透過機架級資源配置，讓運算系統可以依實際應用調整CPU與GPU比例。 \

    \

    對產業供應鏈而言，這項設計提高伺服器CPU、高速記憶體、網路設備及機架整合的重要性，也為AI資料中心提供不同於單純增加GPU數量的擴充方式。AMD與Supermicro、緯穎等系統合作夥伴共同推進相關架構，台灣伺服器製造與散熱供應鏈將是後續商業化的重要環節。 \

    \

    \下一個觀察重點：\ Helion正式系統配置、合作夥伴出貨時程、CPU與GPU混合部署的效能及電力效率，以及大型雲端客戶的實際採用情況。 \

  3. \★★★★★ CPO & Optical｜NVIDIA與Cisco推出USFP光模組架構，單通道400Gbps與12.8Tbps容量推進AI網路升級\ \

    NVIDIA與Cisco於10月12日共同公布USFP高密度可插拔光模組架構，支援每通道400Gbps電訊號，整體連接容量最高12.8Tbps。兩家公司提出的設計目標，是在相近模組空間內，相較既有200Gbps單通道光學方案提高四倍頻寬密度，並改善約1.3倍能源效率。 \Cisco與NVIDIA官方聯合公告\ \

    \

    TE Connectivity與Amphenol參與連接器及硬體生態系開發。新架構將提高光電訊號整合、連接器密度、散熱及高速測試的技術要求，也為光學元件、模組封裝及精密連接器供應商創造新的產品升級機會。 \

    \

    Cisco同日公布，採用Silicon One G300的系統已開始向客戶出貨，新一代G302晶片支援1.6T高速連接，而P200系統已在大型雲端環境正式部署。這些進展反映AI網路正在同步升級交換晶片、光學模組與系統架構。 \Cisco Investor Relations\ \

    \

    對CPO產業而言，USFP也顯示可插拔光學仍持續提高頻寬與功率效率。未來高密度可插拔光模組、共封裝光學與主動式光纜，將依交換容量、傳輸距離、維修便利性與系統成本，在不同網路層級形成分工。 \

    \

    \下一個觀察重點：\ 400Gbps單通道互通性測試、1.6T光學元件供應商、USFP產品量產時程、Cisco新型交換系統出貨，以及光模組與連接器供應鏈的產能擴張。 \

  4. \★★★★☆ XPU / Power｜NVIDIA開放Vera Rubin機架設計，推動高功率密度AI系統的標準化部署\ \

    NVIDIA於10月12日OCP全球峰會宣布，透過MGX架構向開放運算計畫提供Vera Rubin機架與運算模組的關鍵設計，讓系統製造商以共同架構開發下一代AI資料中心設備。Cisco、Google、Meta、Microsoft等企業參與相關生態系合作。 \NVIDIA官方部落格\ \

    \

    新一代機架設計提高了高密度配電、液冷及模組化維護的重要性。隨AI運算功率密度上升，電源轉換效率、匯流排設計、液冷接頭及系統可靠度，將直接影響機架可部署的運算能力。 \

    \

    對台灣供應鏈而言，台達電、光寶科、康舒及相關電力設備、散熱與伺服器系統供應商，將面對更高功率密度與更嚴格系統整合要求。標準化機架有助於供應商共用部分設計與測試流程，提高大型AI園區設備建置效率。 \

    \

    \下一個觀察重點：\ MGX相容系統正式出貨、機架供電規格、液冷設備認證、系統整合商量產時程，以及2027年Vera Rubin相關設備部署進度。 \

  5. \★★★★★ Power｜美國能源監管機構核准PJM大型用電戶登錄制度，資料中心電力需求管理進入新階段\ \

    美國聯邦能源監管委員會10月9日核准PJM建立大型用電戶資料庫，10月12日相關裁定受到市場關注。資料庫將追蹤大型資料中心的設施位置、預計用電時間、用電增加時程、電力供應安排、備援發電及燃料來源。 \Reuters｜10月12日\ \

    \

    PJM服務美國中大西洋及中西部地區約6,700萬人口，預估區域資料中心用電需求至2030年可能增至約29GW，約為目前水準的三倍。資料中心需求快速增加，已使區域容量市場成本顯著提高，並對新增發電與輸電建設形成壓力。 \

    \

    監管機構同時駁回PJM原先提出的部分限電方案。PJM此前希望要求50MW以上的新大型資料中心負擔新增供電資源成本，或在緊急供電情況下面臨暫時斷電安排。後續監管討論將持續影響大型資料中心的供電契約、備援發電與專案開發成本。 \

    \

    \產業影響：\ 大型用電戶登錄制度將提高區域電網對未來負載的掌握能力，協助安排發電、變電站、輸電線路與備援設備投資。對資料中心開發商而言，電力取得時間與供電條件將更直接地影響園區選址、建設進度及資本支出。 \

    \

    對電力設備供應鏈而言，變壓器、開關設備、儲能系統、備援發電與高效率配電設備的需求，將與大型資料中心實際併網及通電時程更加緊密連動。 \

    \

    \下一個觀察重點：\ PJM大型用電戶登錄數據、50MW以上專案的供電安排、區域新增發電與輸電投資、修訂監管方案，以及2027至2030年電力供需缺口變化。 \
