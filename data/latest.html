CPO / Optical｜族群性大漲，AI光互連重新成為資金主線。 Coherent（COHR）上漲約10.7%、Lumentum（LITE）上漲約7.9%、Ciena（CIEN）上漲約7.7%，形成明確cross-company rotation，漲幅顯著高於大盤。主要催化劑之一是Bernstein啟動相關optical / networking公司coverage，將AI data center持續向更高速網路升級視為光通訊供應商的結構性成長動能。

本日重點財經事項

  1. ★★★★★ Power / XPU / AI Server｜JERA、Dell、RHAELM啟動日本400MW AI Data Center，首案投資150億美元

    日本最大發電商JERA、Dell Technologies與AI infrastructure developer RHAELM於10月1日簽署MoU，計畫建立可重複部署的AI infrastructure標準架構。第一個專案位於JERA千葉火力發電廠附近，RHAELM將開發、建造、營運並融資一座400MW級hyperscale AI data center，Apollo Global Management預計擔任策略投資與融資夥伴，Dell則提供標準化rack-scale AI infrastructure。

    專案投資額約150億美元，預計2028年分階段開始營運、2029年達到完整400MW容量；JERA將依15至25年期安排提供400MW電力。Financial Times進一步報導，合作方未來五年規劃在日本推動約3至4GW AI data center與相關發電基礎設施，潛在整體投資規模約1,400億美元。

    影響： 這是今天產業穿透力最高的新事件之一，因為首案同時具備具名地點、400MW電力、150億美元資本、rack-scale compute供應商與2028–2029 COD。JERA把data center直接配置在既有power station附近，也反映AI campus正在嘗試把發電、電氣、冷卻與compute integration前移，以降低grid connection與power availability造成的lead time。若後續3至4GW規劃逐步轉為正式專案，需求將跨越AI server、accelerator、networking、transformer、switchgear、UPS / BBU、液冷與發電設備。現階段應把400MW首案視為較高可信度專案，而後續3至4GW仍屬PLAN；下一個驗證點是正式EPC / equipment orders、rack配置、GPU / XPU平台選擇、IT load與實際power-generation mix。 JERA

  2. ★★★★★ Memory｜Micron長約、deposit與RPO提高2027–2028 Memory需求能見度

    Micron公布FY2026第四季營收542.3億美元，季增31%、年增379%，non-GAAP gross margin達87%。財報與後續資訊顯示，公司目前共有26份長期供應協議，部分合約具有價格floor / ceiling並延伸至2030年；客戶財務承諾約320億美元，remaining performance obligations約1,500億美元。公司表示大部分2027年HBM產出已取得供應協議，並預期FY2027與FY2028的memory / storage供需將比FY2026更加緊張。

    影響： 最重要的訊號不是EPS beat，而是AI memory需求正在由forecast轉化為多年期合約、deposit與future contracted revenue。若更多營收逐漸由長約與price floors支撐，memory產業傳統「價格上升→過度擴產→價格崩跌」的循環振幅可能降低；同時，客戶deposit提高Micron進行capacity planning的需求能見度。

    這並不代表memory cycle消失：RPO不是立即可認列收入，320億美元customer commitments也不能與1,500億美元RPO直接相加。真正決定2027–2028供需是否持續緊張的變數，仍是Micron、Samsung與SK hynix新增wafer capacity的速度，以及HBM對standard DRAM wafer allocation的排擠程度。下一個驗證點是Micron FY2027 CapEx實際增幅、新fab wafer starts，以及Samsung與SK hynix是否同步大幅擴產。 Micron Investor Relations

  3. ★★★★☆ CPO / Optical｜COHR、LITE、CIEN同步大漲，市場重新定價AI光互連與CPO結構性需求

    10月1日AI optical族群出現明確cross-company rally：Coherent（COHR）上漲約10.7%、Lumentum（LITE）上漲約7.9%、Ciena（CIEN）上漲約7.7%，漲幅明顯高於大盤。主要市場催化劑之一是Bernstein啟動相關optical / networking公司coverage，將AI data center向更高速網路升級視為光通訊供應商的結構性成長動能。

    股價催化劑雖然包含sell-side initiation，但背後已有可驗證的基本面支撐。Coherent的PhotonLink平台涵蓋CPO、NPO與chip-to-chip optical connectivity，目前已有超過10個CPO customer engagements、超過10個NPO engagements，兩種架構均已取得anchor customers與long-term agreements，另有超過5個chip-to-chip engagements。公司預計PhotonLink營收自2026年第四季開始ramp，並正在擴充6吋InP與specialty fiber產能。

    影響： 真正重要的是市場開始重新定價AI cluster的下一個瓶頸由compute逐步延伸至interconnect。當GPU / XPU規模與cluster size持續增加，800G→1.6T以及後續CPO / NPO架構會提高每個AI rack與cluster的optical content。Coherent已從產品roadmap進入anchor customer、LTA與revenue ramp階段，使CPO / NPO開始具備commercialization evidence。

    若Lumentum、Coherent與其他供應商後續同步出現1.6T shipment、CPO / NPO qualification與capacity expansion，光通訊可能從AI Infrastructure的二階受惠項目升級為獨立基本面主線。下一個驗證點是1.6T shipment growth、CPO / NPO由engagement轉為volume production、InP / laser capacity utilization，以及具名hyperscaler deployment。 Coherent Yahoo Finance

  4. ★★★★☆ XPU / CSP｜Tencent據報以約70億美元向Oracle租用約10萬顆先進AI晶片

    Financial Times引述知情人士報導，Tencent已與Oracle簽訂五年期海外cloud lease，取得約100,000顆中國境內無法取得的先進AI晶片使用權，晶片將部署於Oracle在東南亞的多座data centers。合約估值約70億美元，並包含約30%的upfront payment。Reuters表示無法獨立驗證該交易，Oracle與Tencent亦未立即正式確認，因此目前應視為高可信媒體報導，但尚未取得交易雙方primary-source confirmation。

    影響： 若最終確認，這筆交易的意義不只在約10萬顆accelerator，而在於中國大型internet company可能把受出口限制的算力需求轉化為境外cloud capacity。這會使中國AI需求不一定直接反映為中國境內GPU shipment，而可能轉化為新加坡、馬來西亞及其他合規地區的data-center deployment與cloud utilization。

    由於交易尚缺乏雙方正式公告，今日將重要性由★★★★★下調為★★★★☆。在Oracle / Tencent確認晶片型號、部署地點與合規架構前，不應把約10萬顆全部計入任何特定GPU供應商訂單。下一個驗證點是交易雙方正式公告、accelerator型號、實際deployment schedule與美國出口管制適用方式。 Reuters
