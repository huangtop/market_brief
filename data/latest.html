本日重點財經事項

  1. ★★★★★ Memory｜Micron：長約客戶財務承諾升至320億美元，多數2027年HBM產出已完成協議

    Micron公布FY2026第四季營收542.29億美元，季增31%、年增379%；non-GAAP gross margin達87.0%，non-GAAP EPS為33.42美元。更重要的是，公司披露Strategic Customer Agreements下的客戶財務承諾已由6月的220億美元增加至320億美元，多數以現金deposit形式提供；相關合約的remaining performance obligations則由前季約1,000億美元升至約1,500億美元。

    Micron同時表示，訂單持續超過現有capacity，預期FY2027與FY2028 memory / storage供需將比FY2026更加緊張；公司已為大部分2027年HBM產出取得供應協議，並將把FY2027 CapEx提高至原先計畫以上。新產能最快約在2027年中開始產出first silicon，但真正對市場形成有意義供給仍需再經數季ramp。

    影響：這次財報最重要的訊號不是EPS beat，而是需求已從forecast轉化為deposit、長約與future contracted revenue。在新增wafer capacity無法快速進入市場的情況下，HBM需求不只支撐HBM本身，也會繼續競爭DRAM wafer allocation。這提高2027年HBM與standard DRAM同時維持緊張的機率，並使Memory成為目前六條AI Infrastructure主線中供需能見度最高的一條。下一個驗證點是Samsung與SK hynix是否同步提高2027–2028 CapEx，以及新增capacity究竟有多少被HBM提前吸收。 Micron Investor Relations Reuters

  2. ★★★★★ XPU / AI Server / Networking｜HPE取得Vultr 12億美元AMD Helios AI Rack訂單

    HPE宣布取得Vultr價值12億美元的AMD Helios AI Rack訂單，將部署於Vultr美國data centers。這是HPE取得的第一筆AMD Helios系統訂單，系統包含AMD AI accelerators以及HPE purpose-built scale-up networking switches與software。

    HPE同時把FY2027 Networking segment revenue growth展望上調至high-teens至low-20%區間，並預估FY2026至FY2029 Networking營收CAGR達high teens。為因應需求與供應限制，公司此前已將networking supply purchase commitments季增一倍。

    影響：這筆訂單是AMD下一代rack-scale AI平台由roadmap進入具名客戶、具金額、具部署地點的實際commercial deployment，因此價值高於一般產品發表。它同時驗證三個方向：AMD accelerator開始取得大型cloud deployment、AI rack價值由GPU延伸至scale-up networking，以及neocloud仍在投入大型AI capacity。下一個驗證點是Helios rack的實際shipment timing、Vultr部署規模，以及AMD平台能否取得第二、第三個大型cloud客戶，確認這不是單一design win。 HPE Investor Relations Reuters

  3. ★★★★☆ AI Server Supply Chain｜Jabil FY2027營收展望445億美元，AI Infrastructure持續推升製造需求

    Jabil公布FY2026第四季營收106.2億美元、年增28.6%，高於市場預期約97.1億美元；公司預估FY2027全年營收445億美元，也高於市場原先約427.9億美元預期。CEO Mike Dastoor指出FY2026已出現顯著AI Infrastructure成長，公司同時把新的關鍵capacity投入營運。

    影響：Jabil位於AI server、networking與相關硬體製造的實際production layer，因此其營收與capacity commentary可作為hyperscaler / OEM CapEx由預算轉為硬體出貨的二階驗證。FY2027財測高於預期表示AI infrastructure manufacturing pipeline尚未出現明顯降速；但由於公司成長同時包含automotive、energy infrastructure等非AI業務，不能把445億美元全部歸因AI。下一個有效訊號是公司揭露AI-related revenue mix、rack / networking production growth與新增capacity utilization。 Jabil Investor Relations Reuters

  4. ★★★★☆ MLCC｜Samsung Electro-Mechanics新增AI Server MLCC / Inductor長約，2026年已揭露供應協議約26億美元

    Samsung Electro-Mechanics最新取得約2,900億韓元、約2.1億美元的AI server MLCC與inductor供應合約，供貨期間為2027年1月至12月。公司今年已連續取得多筆AI相關長期供應協議；依已揭露合約統計，2026年server components供應協議總值約26億美元。

    Samsung Electro-Mechanics表示AI server所使用的MLCC數量超過一般server十倍，公司目前AI server MLCC全球市占超過40%，並持續與其他全球客戶洽談additional LTA。

    影響：這是MLCC主線從「AI可能造成需求增加」進一步轉成2027實際長約鎖量的證據。由於AI server需要高容量、高可靠度並能承受高溫與高電壓的MLCC，可供應的廠商數量低於general-purpose產品；連續LTA增加後，真正需要追蹤的是高階料號capacity utilization與lead time，而不是整體MLCC平均價格。若Murata、TDK、Taiyo Yuden等供應商也開始披露AI-grade capacity expansion或長約，才代表產業正式進入更廣泛的供給重配置階段。 DIGITIMES Samsung Electro-Mechanics
