本日重點財經事項\

\
    \
  1. \★★★★★ XPU / Power｜Nscale與Anthropic洽談第二筆約450億美元AI運算合約，規劃新增460MW Vera Rubin運算容量\ \

    Reuters於10月19日報導，獲NVIDIA投資的英國AI雲端業者Nscale，正與Anthropic洽談另一筆價值約450億美元的運算服務合約。新合作將涉及Nscale位於美國西維吉尼亞州Monarch資料中心園區的第二座設施，規劃提供約460MW運算容量，採用NVIDIA Vera Rubin AI晶片。 \

    \

    Anthropic今年8月已與Nscale簽訂另一筆約450億美元的運算容量租賃合約，涉及Monarch園區第一座設施。根據最新報導，Anthropic也擁有該園區規劃中第三座建築的優先承租權。第二筆合作仍處於洽談階段。 \Reuters｜10月19日Nscale與Anthropic\ \

    \

    \產業影響：\ 新合作將大型AI模型公司的運算需求，直接連結至下一代GPU、機架系統、資料中心供電及長期運算租約。460MW的規劃容量將涉及大規模GPU機架、液冷、變電站、備援電源及高速網路設備投資，並提高Vera Rubin平台在2027年以後的部署能見度。 \

    \

    對NVIDIA及其供應鏈而言，Monarch園區的擴張將帶動先進製程、HBM、CoWoS、機架級電源及光互連需求。對Nscale而言，長期租賃收入與大型客戶信用，將成為安排設備融資及園區建設的重要基礎。 \

    \

    此次消息也使資料中心電力資產的重要性更加突出。Nscale近期在英國的另一項Microsoft合作因電網接入延誤而發生變化，西維吉尼亞州園區的電力安排、工程進度及分階段交付時程，將直接影響新增運算容量的實際部署。 \

    \

    \後續研究重點：\ 第二筆合約最終條款、460MW園區供電安排、Vera Rubin設備採購、分階段建設進度，以及Nscale新增融資結構。 \

  2. \★★★★☆ Power｜大型AI資料中心的電網接入與供電彈性，成為運算容量部署的重要競爭條件\ \

    本週資料中心電力市場的最新變化，集中在大型雲端客戶對園區供電時間的要求。Nscale在西維吉尼亞州推進新一輪運算容量合作，同時英國Loughton專案因電網接入時程延後而調整客戶安排，凸顯不同地區電力基礎設施對資料中心開發速度的直接影響。 \

    \

    美國電力公司與科技企業也持續研究資料中心彈性用電機制，包括在電網尖峰負載期間調整部分運算工作、搭配儲能及自備發電設備，以提高現有電網可承載的資料中心容量。 \Reuters｜資料中心彈性用電與電網\ \

    \

    \產業影響：\ Power主線的投資範圍正由電源供應器及機架配電，擴大至大型變壓器、電網接入、專用發電、儲能與能源管理。資料中心開發商若能同步安排運算設備與電力供應，便能提高建設效率並縮短客戶開始使用運算容量的時間。 \

    \

    對台灣供應鏈而言，高功率電源、800V直流配電、UPS、液冷及電力控制設備，將持續受惠於新一代AI機架的功率密度提升。大型園區建設則帶動高壓變電、開關設備與能源管理系統需求。 \

    \

    \後續研究重點：\ Monarch園區電力接入進度、專用發電與儲能配置、變壓器交期，以及大型雲端客戶對機架級供電與液冷設備的採購規格。 \

  3. \★★★★☆ CPO & Optical｜Optica光子雲端運算峰會今日登場，產業將發布CPO、多芯光纖與矽光子製造規格\ \

    Optica與Advanced Photonics Coalition於10月20日至21日在美國加州Sunnyvale舉行Photonic-Enabled Cloud Computing Summit。官方議程涵蓋AI資料中心光互連、CPO、光學引擎封裝、矽光子製造、光路交換及大規模量產技術。 \

    \

    主辦單位表示，本次峰會將發布由超過60家產業生態系企業參與制定的CPO、多芯光纖及矽光子製造相關規格，重點聚焦製造規模、封裝整合、可靠度與量產部署。 \Optica｜2026光子雲端運算峰會\ \

    \

    \產業影響：\ AI叢集的網路架構正向更高頻寬、更低功耗及更短傳輸延遲發展。CPO與矽光子技術可提高光學元件與交換晶片的整合密度，多芯光纖則提供提高單一連接器傳輸容量的技術方向。 \

    \

    對光通訊供應鏈而言，新規格將影響光學引擎、雷射光源、精密連接器、光纖組裝及自動化測試設備的設計要求。製造標準的建立，也將協助大型雲端業者與設備供應商推進不同平台間的互通性及規模化採購。 \

    \

    \後續研究重點：\ 正式發布的技術規格、參與企業、光學引擎封裝方式、測試標準，以及1.6T與後續高速互連產品的量產規劃。 \
